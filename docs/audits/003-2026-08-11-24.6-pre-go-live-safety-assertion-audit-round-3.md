⭐ **STATED PRECISELY — nothing is crossing today.** The read consumer is un-dispatched (Phase 25.2/25.4). ⚠ **But the WRITE side is already live at boot (`boot.ts:1720`)**, the read side is fully built and merely un-dispatched, and **the natural candidate to wire is the bypass.** ⛔ **What is false TODAY is the ARCHITECTURE claim, not a runtime guarantee.**

### F14 · `GclProjection.visibilityLevel` is self-declared; the gate enforces a ceiling, never a derivation
**Source:** WS-1 · **Severity:** medium · **Safety rule 4** · **→ `### 24.18`**
`validateProjectionVisibility` checks exactly `visibilityRank(declared) <= visibilityRank(workspace.defaultVisibility)` — **a ceiling, not a floor and not a derivation.** ⛔ **Raising `Workspace.defaultVisibility` silently widens what every already-stored self-declared level may cross with.** ⚠ **Graded medium because the gap is self-disclosed in-code as an `arch_gap`** ⇒ not a false assurance of coverage (L96's distinction), and no concrete `ProjectionSource` exists.

### F15 · The "key-name-independent, recursive" raw-content gate misses two container shapes
**Source:** WS-1 · **Severity:** medium · **Safety rule 4** · **→ `### 24.19`**
The traversal recurses via **`Object.entries`**, which sees only own **enumerable string-keyed** properties. **`Map`/`Set` and non-enumerable own properties are `typeof === "object"` yet yield `[]`** ⇒ fall through to *"not raw-content-shaped"* uninspected. ⛔ **And ajv gives no backstop** — `sanitizedPayload.additionalProperties: {}` is unconstrained, so **the Zod refine is the only enforcement, not defence-in-depth.** ⚠ Nested arrays/objects **are** handled — the module's own adversarial tests stop exactly there. ⭐ **No end-to-end leak in wired code; the finding is that the stated guarantee is false and nothing tests the boundary.**
