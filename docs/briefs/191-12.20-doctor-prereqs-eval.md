## Acceptance criteria (what "done" means)
- [ ] The suite IMPORTS the landed pure surface (never edits it): `runDoctor(snapshot)→DoctorReport` + `safeCheck` (`apps/worker/src/install/doctor.ts`), the diagnosers (`checks/environment.ts`, `checks/posture.ts`), the `ProbeSnapshot` shape (`probe-snapshot.ts`), and the contract `DOCTOR_CHECK_IDS`/`DoctorReport`/`rollUpStatus` (`packages/contracts/src/install/doctor-result.ts`). Scores via the `packages/evals/src/harness` runner + criteria-registry.
- [ ] **Write-through posture fail-CLOSED:** each of the 3 posture checks (`vault_acl` / `gbrain_readonly_mount` / `stray_gbrain_process`) maps an **absent or malformed** probe to `finding` — **never a silent `ok`** (assume-worst, safety-rule-1 / L8).
- [ ] **Loopback-only:** an occupied `loopback_ports` probe → `finding`.
- [ ] **Pin integrity:** `gbrain_startable` / pin checks → `degraded`/`finding`; the doctor never reports green on an unpinned/unvalidated gbrain.
- [ ] **`overall` is a DERIVED worst-of** (`ok < degraded < finding` via `rollUpStatus`) — a single check `finding` is never masked to a green overall.
- [ ] A **thrown** probe folds to `probe_error` (§16) — the engine never throws.
- [ ] **Non-vacuity (L7):** every fail-closed `finding` assertion pairs with an **all-`ok` snapshot** proving that check CAN pass; the suite is verified by INVERTING one posture probe (`ok`→`finding`) and observing the score flip.
- [ ] **Hard 100% floor (L27):** the posture/loopback/pin fail-closed set scores at a hard 100% (safety invariant — not a soft ratio).
- [ ] The suite closes the row-8 / coverage-matrix mapping (criteria points at this file); `clean-install.test.ts` ships as an `it.todo` stub so the acceptance row is visibly TRACKED, not silently missing.
- [ ] **Deterministic / provider-free / gbrain-free** — pure engine over injected snapshots; no network, no live services, no real gbrain.
- [ ] All tests in `packages/evals/suites/clean-install/doctor-prereqs.test.ts` pass; `/preflight` clean.

## RED test outline (packages/evals/suites/clean-install/doctor-prereqs.test.ts)
1. **`all_ok_snapshot_passes`** — a fully-`ok` `ProbeSnapshot` → `overall:ok`, every check `ok`. Asserts: the positive anchor (machinery CAN pass). Why: L7 non-vacuity.
2. **`posture_absent_probe_fails_closed`** — an absent/malformed `vault_acl`/`gbrain_readonly_mount`/`stray_gbrain_process` probe → `finding`, `overall:finding`. Why: safety-rule-1 assume-worst (L8).
3. **`loopback_occupied_finding`** — occupied `loopback_ports` → `finding`. Why: loopback-only isolation.
4. **`unpinned_gbrain_never_green`** — unpinned/unvalidated pin → `degraded`/`finding`, never `ok`. Why: §13 pin integrity (L21).
5. **`overall_worst_of_not_masked`** — one check `finding` + others `ok` → `overall:finding`. Why: derived worst-of, no green mask.
6. **`thrown_probe_folds_to_probe_error`** — a throwing probe → `probe_error`, no throw. Why: §16 TOTAL.
7. **`inverted_guard_flips_score`** — flip one posture probe `ok`→`finding` and assert the acceptance score flips (kills a vacuous suite). Why: L7 verify-by-inversion.
