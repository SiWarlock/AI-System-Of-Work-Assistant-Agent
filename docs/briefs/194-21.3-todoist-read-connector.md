## Acceptance criteria (what "done" means)
- [ ] `createTodoistConnector(transport)` returns a `ConnectorPort` via `makeConnector({connectorId:"todoist", readScope:<least-privilege READ scope>}, transport)`.
- [ ] `createTodoistHttpTransport(deps)` builds the read-only HTTP transport via `createConnectorHttpTransport(TODOIST_HTTP_SPEC, deps)` — SSRF-guarded (allowedHosts = the Todoist API host), Bearer token from the injected SecretsAccessor (fail-closed on unavailable/throw), `Number.isInteger` 2xx gate, redacted typed faults, TOTAL never-throws.
- [ ] `mapPage` parses the Todoist candidate envelope FAIL-CLOSED → `TransportItem[]` (`{id, hash, raw}`); a missing/renamed field or malformed entry ⇒ `TransportFailure`, never a false/empty page; `contentHash` via `payloadHash` over the change token (or the raw task if the token field is absent).
- [ ] Cursor/paging per the Todoist wire shape (REST v2 `/tasks` may be a single unpaged array ⇒ `done:true` one page — confirm on Context7); a tampered/persisted cursor is `encodeURIComponent`-encoded (defense-in-depth on top of the template SSRF guard).
- [ ] **Emit-only (rule 1):** feeds the ingestion path's `registerSource()` candidate gate — never writes Markdown; no `@sow/knowledge`/fs-write import (the L12 write-surface scan stays green). **ING-7:** the ingested task content is untrusted (the downstream extraction agent runs read-only).
- [ ] **Dormant:** the real HttpTransport + Todoist token SecretsAccessor stay UNBOUND (faked in tests; real bind = §ARM-23 owner crossing — real external network I/O). No real network/clock in the adapter or tests.
- [ ] All unit tests in `packages/integrations/test/todoist-read.test.ts` pass; `/preflight` clean.
