# /tdd brief — processor_of_route_is_total

## Feature

Make `processorOfRoute` total: a malformed route identity must **deny**, never throw.

## Use case + traceability

- **Task ID:** 9.33 (task-list #25)
- **Architecture sections it implements:** `ARCHITECTURE.md §5` (egress veto / processor identity), `§16` (typed errors, never throw across a boundary)
- **Related context:** contracts **L78** (totality is a property of the whole fold, not the guard you wrote) — this task IS that lesson's worked example · found by provint during task #21

## Verified premise (falsify first)

`processorOfRoute` documents itself pure and fail-closed, and its malformed-route branches correctly return
`processorId("MALFORMED_ROUTE")` (egress, never non-egress). **Then it brands the route's raw identity**, and the
brand constructor **throws on a blank string** — so `{provider: ""}` from a deserialized row **throws instead of
denying.** The guards are exhaustive over the cases enumerated; the throw lives *after* them.

## Why this matters beyond tidiness

`processorOfRoute` is the identity layer directly beneath the **egress veto**. A throw on an untrusted route is a
**fail-open-by-crash on a rule-5 path** — the caller does not get a deny, it gets an exception, and whether that
denies depends entirely on the caller's error handling. provint contained it at their own boundary (one `try` ⇒
deny), which protects *that* caller and leaves **every other one exposed**. That is why this is a task and not a
call-site fix.

## Acceptance criteria

- [ ] `processorOfRoute({provider: ""})` returns the `MALFORMED_ROUTE` processor — it does not throw.
- [ ] Same for the runtime branch (`{runtime: ""}`) and any other identity the brand would reject
      (whitespace-only if the brand rejects it — establish what the brand actually rejects rather than assuming).
- [ ] The existing malformed-route branches (null / non-object / neither-key / both-keys) are unchanged — assert,
      don't assume.
- [ ] **No route that previously returned `null` (genuine non-egress) now returns a processor, and none that
      returned a processor now returns `null`.** This is the safety-critical no-drift pin: the fix must change
      only throw→deny, never the egress classification of any well-formed route.
- [ ] A caller audit is reported at Step 9: which callers relied on the throw, and do any need updating.
- [ ] `/preflight` clean.
