## The actual question

**Post-`24.26`, `KnowledgeWriterDeps.workspacePathCheck` is REQUIRED.** In well-typed code, omission is unrepresentable. **The only remaining path to a non-function value is an explicit `as`-cast**, which is unbounded by construction.

**FOR a guard:** §16 promises never-throw. Today a cast-produced deps object yields a **TypeError at the invocation site**, not a typed `WriteFailure` — **a genuine §16 gap**, reachable only via cast.

**AGAINST:** it defends against a caller who has already **explicitly lied to the type system**; every such guard adds a branch that must itself be tested and can rot. `contracts L103` argues the type is the mechanism and a runtime check is belt — **and belt that is mislabelled as mechanism is how a later reader improves the mechanism away.**
