## Acceptance criteria (what "done" means)
- [ ] `parseReadabilityHtml(html, url)` maps HTML → a `WebPage` candidate with **`text ← textContent`** (NOT the raw `content`/innerHTML), or a typed fault — over fixture bytes, **zero network**, never throws.
- [ ] Empty / null / whitespace-only readability output → a typed **`empty_content`** fault (matching `web-source.ts`'s existing fault set), never a contentless `WebPage`.
- [ ] `createWebFetchTransport({httpGet})` SSRF-guards the **FINAL** url via the single vetted `isAllowedRemoteEndpoint` predicate **BEFORE** any fetch; a rejected/loopback/non-allowlisted endpoint → typed fault with **ZERO bytes fetched** (guard-before-fetch, L4 authority-isolation reused, never re-mirrored).
- [ ] The transport threads `httpGet` (injected) → `parseReadabilityHtml`; a throwing / non-2xx / pathological-body `httpGet` → redacted typed `TransportFailure` behind the positive-2xx gate; **TOTAL never-throws** (whole post-fetch map under one try — L11).

- [ ] **Dormant:** the real `httpGet` is unbound at boot (shipped default byte-equivalent); a grep shows zero production callers binding a real network `httpGet`.
- [ ] All unit tests in `packages/integrations/test/web-fetch-transport.test.ts` pass; `/preflight` clean.
