# /tdd brief — health_item_dedupe_key_collapse

## Feature

## Lessons-logged candidates anticipated

- **Convention candidate** — *a dedupe key over a many-to-one classification silently merges causes with different operator responses; the key must carry whatever the operator is expected to act on differently.*

- **Architecture-doc note candidate** — §16/§10.3 gain an explicit statement of what health-item identity is, and what it deliberately collapses.
