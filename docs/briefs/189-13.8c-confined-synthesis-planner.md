## Acceptance criteria (what "done" means)
- [ ] `planSynthesis(input, deps)` returns a typed `Result` carrying **0–2** `KnowledgeMutationPlan`s: at most one **additive-auto** plan (`requiresApproval:false`) + at most one **human-relevant-propose** plan (`requiresApproval:true`); empty plan set when there is nothing to synthesize. **TOTAL never-throws.**
- [ ] Additive/derived effects — a NEW synthesis note (`NoteCreate`), a NEW `@generated` region (`NotePatch` into a generated region id), a faithful healed forward `LinkMutation` — land in the **auto** plan with `requiresApproval:false`.
- [ ] Human-relevant edits — a patch that changes an existing human-relevant claim, a status/owner `FrontmatterPatch` flip, an entity-merge — land in the **propose** plan with `requiresApproval:true`. **The tier is classified DETERMINISTICALLY by the planner (effect kind + target), never self-declared by the model candidate.**
- [ ] **`@user` confinement (SAFETY):** NO emitted `NotePatch` ever targets a human/`@user` region — patches target only `@generated`/`kw:region` region ids; a proposed effect whose target is a human region is **dropped/withheld** at plan-assembly. Pinned with a note carrying BOTH a `@user` and a `@generated` region: only the generated region id is ever patched.
- [ ] **No-inference (REQ-F-017):** a frontmatter value (owner/date) lacking an `evidenceRef` is coerced to `TBD` (owner/date) or the update is dropped — an invented value is NEVER emitted. Reuses the domain `validateNoInference` oracle over the candidate.
- [ ] **SENSE grounding:** entity references resolve through `resolveEntity` (resolve / create-stub / withheld); a `withheld` entity yields NO fabricated path (no create, no patch); links heal through `healLinks` (faithful-or-withhold). A `withheld`/`create_stub` never produces a patch to a non-existent note.
- [ ] Every emitted KMP passes the candidate-data gate: **non-empty `sourceRefs`** (REQ-F-006), `.strict()` parse succeeds, `confidence ∈ [0,1]`, `workspaceId` set.
- [ ] **PURE** over injected ports (gbrain read, reason port, section-provider); a malformed model candidate / faulted read → fail-safe empty (or partial-valid) plan set, never a throw (L11).
- [ ] **Dormant:** no production caller — `grep` shows zero non-test importers of `planSynthesis` (wiring is 13.8d/13.8f).
- [ ] All unit tests in `packages/knowledge/test/synthesis-planner.test.ts` pass; `/preflight` clean.

## Things to flag at Step 2.5
1. **Plan splitting — ≤2 KMPs (additive-auto + human-relevant-propose) vs ONE OR'd plan?** My default vote: **split into ≤2**. A single plan carries ONE `requiresApproval` boolean; OR-ing it forces the whole run to PROPOSE the moment any effect is human-relevant, defeating the KN-10 auto-apply payoff. Two plans keep additive writes auto-applying. (Load-bearing for the keystone's value.)
2. **Tier classification authority — planner-deterministic vs model-self-declared?** Default: **planner classifies deterministically** from effect kind + target (new region/note/link = additive; edit-to-existing-human-claim / status-owner flip / merge = human-relevant). Never trust the model candidate to set its own approval gate (safety rule 2 candidate-data; deterministic-before-latent).
3. **`@user` confinement mechanism.** Default: **plan-assembly confinement** — the SENSE phase supplies each target note's region descriptors (via a `SectionProviderPort` backed by `parseSections`/`listRegionIds`); the planner emits patches ONLY to region ids of kind `generated`, DROPPING any effect whose target is a human/`@user` region. KnowledgeWriter's KN-7 rejection remains the downstream backstop. (The Done-when demands "provably never overwritten" AT the plan, so drop-at-emit is required, not just KW backstop.)
4. **No-inference coercion — `TBD` vs drop?** Default: **`TBD`-coerce** for owner/date (REQ-F-017 literally says "emit `TBD`"), **drop** the update for any other un-evidenced field. Reuse the domain oracle so the rule lives once.
5. **`provenanceOrigin` for a synthesis KMP.** The enum (`human/meeting_close/ingestion/gbrain_proposal/parity_remediation/project_capture/project_sync/copilot_propose`) has **no** synthesis member. Default: **the planner takes `provenanceOrigin` as a construction INPUT (existing enum) and ships origin-agnostic/dormant** — DEFER the dedicated `living_vault_synthesis` frozen member to the 13.8d wiring round (when the §6 stance revision + binding land). This keeps the keystone unblocked (no serial contract dependency now). Push back if you think the auto vs propose plans need distinct origins baked in here.
6. **REASON port + no-inference import.** Default: a knowledge-local `SynthesisReasonPort` returning a knowledge-local `SynthesisCandidate` type (proposed per-entity region bodies + claims + `evidenceRef`s — NOT a frozen contract, mirrors `EntityRef`/`LinkRef`), faked in unit tests. For no-inference, reuse `@sow/domain` `validateNoInference` **if** the knowledge→domain import direction permits (knowledge→policy→{domain,contracts}); if a direct import is disallowed by the boundary test, express the evidence-presence guard locally over the candidate's `evidenceRef`s and flag it. Verify at Step 1.
