# /tdd brief — raw_content_gate_must_traverse_map_set_and_non_enumerable_shapes

## Feature
Close the gap where `GclProjection`'s "key-name-independent, recursive" raw-content gate falsely claims full coverage: its traversal uses `Object.entries`, which yields `[]` for `Map`/`Set` instances and skips non-enumerable own properties — so a raw multi-line/oversized string hidden inside either shape passes the gate silently, contradicting the gate's own in-code claim.
