## Feature
The §12 DoD **worker-API auth suite** (in `packages/evals`, evalsec territory): pins that EVERY tRPC call AND the WS/SSE handshake require a valid per-launch session token, and the strict Origin/Host allowlist rejects a disallowed origin (anti DNS-rebind) — even from loopback ("loopback binding is NOT authentication"). ## Acceptance criteria (what "done" means)
- [ ] Every tRPC call requires a valid per-launch session token — a call with a missing/wrong token is **rejected**, one with the valid token passes. (§5 auth)
- [ ] The **WS/SSE handshake also requires** the valid session token — an unauthenticated handshake is rejected (closes the "every WS/SSE handshake" clause, not just the request path).
- [ ] The strict **Origin/Host allowlist rejects a disallowed Origin/Host** (anti DNS-rebind) — including a request from loopback (loopback binding is NOT authentication; §5 / §5 auth denial).
- [ ] The suite drives the **REAL exported auth boundary** (interceptor + `WorkerOriginAllowlist` + the server context factory / `pushStream` handshake) — not a re-implementation of the check.
- [ ] Deterministic — fixed-rng session tokens (mirror `auth-suite.ts`); provider-free, no live infra.
- [ ] The suite runs green; `/preflight` clean.

## RED test outline (Step 2)
1. **`trpc_call_requires_session_token`** — missing/wrong token → rejected; valid token → passes. Why: §5 per-launch session-token auth.
2. **`ws_sse_handshake_requires_session_token`** — an unauthenticated WS/SSE handshake is rejected. Why: §5 ("every WS/SSE handshake" clause).
3. **`disallowed_origin_rejected_anti_rebind`** — a request with a disallowed Origin/Host is rejected via `WorkerOriginAllowlist`. Why: §5/§5 anti-DNS-rebind.
4. **`loopback_is_not_auth`** — a loopback-origin request with a bad token/origin is still rejected (loopback binding ≠ authentication). Why: §5 (the load-bearing posture).
5. **`valid_token_and_origin_passes`** — a positive control: valid token + allowlisted origin passes on both the request and handshake paths. Why: no false-reject.
