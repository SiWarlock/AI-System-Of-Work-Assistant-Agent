# /tdd brief — entity_resolver_ground_before_write

## Feature
The **EntityResolver** (packages/knowledge/src/synthesis/) — resolves a referenced entity (person/project/concept) to an EXISTING canonical vault note path via a workspace-scoped GBrain read (WS-8), returning a **resolved path**, a **create-stub decision**, or **withheld/unresolved** — and NEVER fabricates a path. Pure over an injected GBrain read port; never-throws; fail-closed to unresolved. This is the net-new load-bearing gap (no resolver exists today) and the ⭐ start of the ARC-4 §13.8 keystone.

## Acceptance criteria (what "done" means)
- [ ] `resolve(entityRef, workspaceId)` over an injected workspace-scoped GBrain read port returns a **RESOLVED existing canonical note path** on an exact-slug/alias match.
- [ ] **No existing note** ⇒ a **create-stub decision** (carrying the proposed slug for the planner to create) — distinct from "unresolved".
- [ ] **Ambiguous (2+ candidates) or lossy match ⇒ WITHHELD** (never a fabricated path, never an arbitrary pick) + flagged for clarification.
- [ ] **WS-8:** the GBrain read is workspace-scoped — a test proves the resolver **NEVER resolves across workspaces** (no cross-brain query, safety rule 4); a cross-workspace hit is not returned.
- [ ] PURE over the injected read port; **never-throws**; **fail-closed to "unresolved"** on any GBrain fault/empty/malformed.
- [ ] A synthesis-named non-existent path is **NEVER returned as "resolved"** (the load-bearing ground-before-write property).
- [ ] All unit tests in `packages/knowledge/test/synthesis/…` pass; `/preflight` clean.
