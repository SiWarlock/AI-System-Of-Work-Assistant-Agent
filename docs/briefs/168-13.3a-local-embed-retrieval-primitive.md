# /tdd brief — local_embed_retrieval_primitive

## Feature
A local, zero-egress semantic retrieval primitive (`local-embed.ts`) that wraps Ollama / LM Studio embeddings behind `ModelProviderPort` with RRF hybrid fusion, as GBrain's local retrieval path — the embedding index lives OUTSIDE the canonical Markdown tree (rebuildable/read-only), and the `openai` cloud embed backend is egress-vetoed for employer-work (fail closed, never a cloud fallback).

> **Scope note (13.3 split):** this brief is **13.3a — the retrieval primitive** (knowledge territory). The paired **13.3b retrieval eval harness** (`packages/evals/src/retrieval/`, recall@10 ≥ ~0.91 bar — §13.1c pin re-validation) lands as a **separate evalsec-track slice** that depends on this one (`packages/evals` is eval-security territory). 13.3's plan checkbox stays `[~]` until both legs land.
