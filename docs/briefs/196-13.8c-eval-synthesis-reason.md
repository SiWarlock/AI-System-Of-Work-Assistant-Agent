## Acceptance criteria (what "done" means)
- [ ] The suite runs `planSynthesis` over a labeled corpus (≥20 source-contexts — the §12 floor, matches meetingCloseout) with each entry's RECORDED `SynthesisCandidate` replayed through a fake `SynthesisReasonPort`; **provider-free / deterministic** (no model / network / clock / random).
- [ ] **SAFETY invariants — asserted DIRECTLY, HARD 100% floor (L27, mirror 12.16):** for every corpus entry — tiering correct (additive/heal/@generated-refresh → AUTO `requiresApproval:false`; owner/status/date frontmatter → PROPOSE `requiresApproval:true`); a `@user`/marker-unsafe region id is NEVER in any emitted patch (dropped); a mislabelled `refresh`-unknown / `new_region`-collision is dropped; un-evidenced owner/date → `TBD`, other un-evidenced → dropped; every emitted plan re-parses through `KnowledgeMutationPlanSchema` (candidate gate). Score exactly `1.0` — one leak fails the suite.
- [ ] **FAITHFULNESS (entity-grounding), hard 0-count on fabrication:** a `withheld` entityRef fabricates NO path; only `create_stub` mints a stub; a `resolved` entity creates nothing; healed links only on a faithful slug match.
- [ ] **Non-vacuity (L7):** each fail-closed assertion is paired with a POSITIVE anchor that IS emitted (a @user-drop paired with a legit region patch that lands; a TBD-coercion paired with an evidenced value preserved verbatim; a withheld-no-fabrication paired with a resolved path used + a stub minted). The suite is verified by INVERTING each fixture (flip @user→safe id, add evidence, resolve the entity) and asserting the effect NOW appears — proving the guard, not an always-empty plan.
- [ ] A `synthesis` corpus floor is registered so a shrunk corpus fails (mirror `CORPUS_FLOORS`).
- [ ] (Optional, Q3) a real-model live-`SynthesisReasonPort` leg ships as an owner-gated `it.todo`/`requiresRealIntegration` stub (dormant — mirrors 12.16's deferred e2e).
- [ ] All tests in `packages/evals/suites/synthesis/synthesis-reason.test.ts` pass; `/preflight` clean.
