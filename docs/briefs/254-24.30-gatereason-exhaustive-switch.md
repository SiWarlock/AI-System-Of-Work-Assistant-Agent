# /tdd brief — gate_reason_exhaustive_switch_no_default_absorb

## Feature
`global-markdown-reconcile.ts`'s `gateReason()` switches over `GclGateError.code` with a `default:` branch that silently reclassifies both `visibility_type_mismatch` (added by `24.18`) and the pre-existing `malformed_policy_input` as `"schema_rejected"` in the operator-facing rejection message. Make the switch exhaustive so a real, distinct reason is never silently absorbed into the wrong label — the exact `L134` shape (a `default:` over a closed union), caught here before it shipped a second time.
