## RED test outline
1. **`renders_priority_order_verbatim`** — items render in served order, never re-sorted. Why: §11 pre-ranked + Lesson 31.
2. **`absent_priority_no_badge`** — an item with no `priority` renders no priority badge (never a guessed value). Why: REQ-F-017.
3. **`empty_state_no_tasks`** — empty slice → "No tasks" `role="status"`. Why: honest empty-state.
4. **`hydrate_unwraps_items_and_drops_leaky`** — `query.taskRollup` `{items:[valid, leaky]}` → only valid lands (per-row safeParse drop). Why: fail-closed display + the `{items}` unwrap gotcha.
5. **`reducer_scope_replace_and_clear`** — `replaceTaskRollup` replaces whole-list; cleared to `[]` under Global (WS-8). Why: scope-replace + no cross-workspace blend.
6. **`renders_only_allowlisted_fields`** — no raw/extra field leaks into the DOM (no spread). Why: WS-8 display boundary.
7. **`hydrate_never_throws_stale_scope_bails`** — a fault / stale-scope → no throw, no stale write. Why: TOTAL + scoped-hydrate correctness.
