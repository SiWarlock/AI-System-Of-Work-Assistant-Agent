### (3) ⭐⭐ AND THE PART THAT MOST CHANGES THE SLICE — THE DESKTOP RENDERER IS ALREADY SAFE, BY AN ACCIDENT NOBODY WROTE DOWN

`foldStatus` (`apps/desktop/renderer/lib/egress-status.ts`) does two things the task entry does not account for:
1. It **compares** the returned `v["workspaceId"]` against **the caller's own input** and **fails closed** (`{ok:false}`) on mismatch.

⇒ ⛔⛔ **THE STORE'S VALUE IS USED AS AN EQUALITY CHECK AND THEN DISCARDED. WHAT REACHES THE RENDERED SURFACE IS THE STRING THE CALLER ALREADY HAD.**

⚠⚠ **DO NOT READ THIS AS "`### 24.102` IS A NON-ISSUE."
