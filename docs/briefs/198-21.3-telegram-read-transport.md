- [ ] Offset cursor: `getUpdates?offset=<last update_id + 1>&limit=<n>`; a persisted/tampered cursor is `encodeURIComponent`-encoded; an empty `result:[]` ⇒ `ok`/0-items/`done`.

## Things to flag at Step 2.5
1. **⚠ Token-in-path injection.** Default: extend/parameterize the template's auth to a secret-aware PATH builder (`/bot<secret>/…`) if it doesn't already support it; ensure the SSRF-host-ref + redaction strip the token so it never logs. 2. **Change token for `contentHash`?** Default: `update_id` (monotonic per bot) → `payloadHash({update_id})` or the raw update; confirm on Context7.
3. **Which update types to ingest?** Default: `message` (text) updates as candidate-data; other update types (edited/channel/callback) are an arming-era ingestion-richness call — start minimal, never fabricate.
4. **Long-poll `timeout` param?** Default: omit (single-shot `getUpdates` over the injected transport; long-poll timeout is an arming-era transport concern) — confirm on Context7.
