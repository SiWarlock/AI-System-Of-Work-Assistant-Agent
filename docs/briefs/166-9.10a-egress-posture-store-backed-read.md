# /tdd brief — egress_posture_store_backed_read (9.10 Brief A)

## Feature
Make the Employer-Work egress veto read the **durable** per-workspace acknowledgment state instead of a hardcoded fail-closed constant: introduce a store-backed `WorkspacePostureResolver` that reads `WorkspaceConfigRepository.get(workspaceId).egressPolicy`, and swap the **four** current per-request posture-derivation sites (plus back `systemHealth.egressStatus`) to use it. **Byte-equivalent by default** — provisioned workspaces persist `employerRawEgressAcknowledged: false`, so nothing changes behaviorally until Brief B adds the acknowledge command. This is the safety foundation for 9.10 (owner-approved D1=A).

> **Widens phase scope because** it implements the `§5` egress-veto / `§16` System-Health egress-status seam (per the task's REQ-S-002 spec), not Phase-9's `§11` UI anchor — the veto-input plumbing behind the 9.10 surface.
