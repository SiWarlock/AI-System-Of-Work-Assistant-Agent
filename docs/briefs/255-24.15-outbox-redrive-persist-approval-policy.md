# /tdd brief — outbox_redrive_persists_original_approval_policy

## Feature
Outbox redrive reconstructs `approvalPolicy` as a hardcoded `"queued"` literal because `OutboxEntry` never persists the original policy — so an entry held for an unrelated transport failure (`"unreachable"`) whose original action was auto-eligible gets redriven with unnecessary approval gating. Fail-safe direction (more gating, never less — not a rule-3 breach), but the claim isn't derived from the entry's real governing state. Persist the original policy (or just the was-auto-eligible bit) so redrive reconstructs a faithful action.
