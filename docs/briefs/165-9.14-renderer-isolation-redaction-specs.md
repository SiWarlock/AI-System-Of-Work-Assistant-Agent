# /tdd brief — renderer_isolation_and_redaction_adversarial_specs

## Feature

## Acceptance criteria (what "done" means)
- [ ] `apps/desktop/test/security/renderer-isolation.spec.ts` asserts: `contextIsolation` on / `nodeIntegration` off; the renderer-reachable bridge surface **equals** `preload/inventory.json` (no extra privileged channel); a simulated XSS context cannot reach `require` / `process` / `ipcRenderer` / Node globals; invoking a non-enumerated channel fails.

5. **`poisoned_event_logs_no_secret`** — no secret/token/raw value reaches `console.*` during the fold. Asserts: no-secrets-in-renderer-logs. Why: §16 redaction.
