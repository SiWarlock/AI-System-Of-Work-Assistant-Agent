# /tdd brief — link_healer_governed_auto_link

## Feature
The **LinkHealer** (packages/knowledge/src/synthesis/) — the governed port of osb's `heal_links.py`: given a note's `Title`→slug references, emit corrective `LinkMutation{op:'add', srcPath, dstSlug}` ONLY on a faithful/unambiguous slug match; a lossy / fuzzy / 2+-candidate match is WITHHELD to a proposed clarification (never auto-healed). Backlinks are NEVER authored (derived read-only via GBrain). PURE, deterministic, never-throws; every mutation flows through the KMP → KnowledgeWriter (never a direct write). The 2nd ARC-4 §13.8 keystone slice.
