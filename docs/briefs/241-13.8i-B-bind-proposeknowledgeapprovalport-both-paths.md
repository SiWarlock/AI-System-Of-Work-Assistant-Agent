## ⭐ THE SINK — worker's option (a) is APPROVED, and it is v1's WORDING that was wrong
**Construct a fresh `createApprovalsKnowledgeProposeSink(...)` at the real composition
root**, over the same repos (`backends.repos.approvals`,
`backends.repos.pendingKnowledgeMutations`, `backends.repos.workspaceConfig`,
`backends.now`), then wrap it with the **existing** factory
`createProposeKnowledgeApprovalPort` (`apps/worker/src/composition/living-vault.ts:288`,
already contract-pinned in `apps/worker/test/living-vault-propose-approval.test.ts`).

⛔ **v1 said *"never a second sink."* That phrase is CORRECTED, and the correction is the
lesson:** it was aimed at a second **MINTING PATH**. Two objects over the identical repos
with planId idempotency are **one minting path instantiated twice.** ⇒ **the prohibition
is on the BEHAVIOUR, not the OBJECT:**
> **FORBIDDEN:** any second code path that can mint an Approval — a different repo, a
> different write, a bypass of planId idempotency, a parallel propose port.
> **PERMITTED:** a second sink *object* over the same repos and the same idempotency.
⭐ *A prohibition written against the wrong noun forbids the correct fix.*

⛔ **AND DO NOT REACH FOR THE EXISTING INSTANCE — v1's central error.** `boot.ts:1756`'s
`knowledgeProposeSink` is inside the body of `agentSynthesisFactory` (`boot.ts:1735`), a
**lazy** `() => CopilotSynthesisPort` that is (a) only *defined* when
`config.copilotRealModel === true && config.copilotAgentMode === true` and (b) only *run*
when invoked, per-ask. **There is no boot-time instance to wrap, and it belongs to a
different feature** (the Copilot chat agent's own §13.10a/C5.3 propose-knowledge tool).

⭐ **LEAD-RULED, AND SAY IT IN THE COMMIT: binding through that factory would have been
WORSE THAN UNBOUND.** An unbound port is a **visible gap**. A port bound through
`copilotRealModel && copilotAgentMode` is living-vault propose-routing that silently works
or doesn't **depending on an unrelated feature's enablement** — a false green whose
discovery method is *somebody toggles Copilot off.*
