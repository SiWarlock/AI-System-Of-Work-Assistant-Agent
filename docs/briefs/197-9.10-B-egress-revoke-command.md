# /tdd brief — egress_ack_revoke_command (9.10-B) ⚠ rule-5 SAFETY

## Feature
The owner-authorized **egress-ack REVOKE command** (worker): flips a workspace's `EgressPolicy.employerRawEgressAcknowledged` → `false` AND clears `acknowledgedAt` (both move together per the model refine), through the 9.10-A store path (`WorkspaceConfigRepository` get→upsert with the immutable-binding guard), audited, fail-closed. The fail-SAFE direction (turns employer cloud egress OFF) — the REVOKE half of the re-scoped 9.10-B. The VISIBILITY leg already exists (`systemHealth.egressStatus`); this slice adds the missing command + a non-vacuous visibility pin.

## Acceptance criteria (what "done" means)
- [ ] An owner-authorized `revokeEgressAck(workspaceId)` mutation (behind `authedResolver`, mirror `crossWorkspaceLink.revoke`): reads `WorkspaceConfigRepository.get(wsId)` → sets `egressPolicy.employerRawEgressAcknowledged=false` **AND clears `acknowledgedAt`** (both together — the refine rejects ack=false with a lingering timestamp) → `upsert(ws)` → appends an `AuditRecord`. Returns the new `UiSafeEgressStatus`.
- [ ] **Immutable-binding guard (L30):** get-before-upsert; the revoke is a same-`type` overwrite of ONLY the ack fields (never mutates id/type/other bindings); **fail-closed on any store fault** (never upsert on unknown prior state — a missing/faulted workspace → typed error, no write).
- [ ] **Preserve-fault (rule-5):** an absent/faulted workspace never yields a fault-time default; the command fails closed (typed error), the visibility read stays `{ack:false, zeroEgressOnly:true}`.
- [ ] **Audited (§4, rule-7):** `AuditRecord{actor:'owner', event:'egress_ack_revoked', refs:[workspaceId], before/afterSummary: ack true→false (SUMMARIES only — no raw content/policy dump), workspaceId, timestamp}`.
- [ ] **Visibility pin (non-vacuous):** a test proving `systemHealth.egressStatus` reflects ack=true BEFORE revoke and ack=false AFTER (the revoke actually flips what the visibility surfaces) — pairs the negative (revoked→off) with the positive (acked→on).
- [ ] TOTAL never-throws (typed `Result`/errors); no raw content or secrets in any error/audit (rule 7).
- [ ] All unit tests in `apps/worker/test/api/procedures/egressCommands.test.ts` (+ assembled/live) pass; `/preflight` clean.
