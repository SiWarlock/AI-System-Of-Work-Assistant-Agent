## ⭐ THE ARCHITECTURAL CONSTRAINT — established by worker at 13.8f-B scoping, and it decides the file list
`packages/workflows/src/ports/meetingCloseout.ts:325` states *"buildOutputs runs BEFORE any durable
write."* The only sibling-plan commit this project has ever done is
`packages/workflows/src/workflows/sourceIngestion.ts:472-549`, and it does **rewrite → MAIN commit →
sibling loop, IN THE WORKFLOW.**

⛔ **If the ACTIVITY committed siblings internally, a later failure inside the same `build()` call would
leave sibling plans DURABLY COMMITTED while the call returns an error** — a partial commit exactly where
this codebase went out of its way to prevent one. ⭐ **The distinction that let 13.8f-B stay narrow: the
hazard is in COMMITTING siblings, never in CALLING the rewrite** (which returns data and performs no
durable write). ⇒ **the sibling loop belongs in `workflows/meetingCloseout.ts`, after its step-5 main
commit** (`:338` `deps.commit.commit(plan)`), mirroring the source path's ordering.
