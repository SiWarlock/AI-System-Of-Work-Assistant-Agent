## Acceptance criteria (what "done" means)
- [ ] `buildWriteAdapterRegistry(adapterDeps)` returns an **exhaustive `Record<TargetSystem, adapter>`** — each of the seven targets (`calendar`, `todoist`, `linear`, `asana`, `drive`, `github`, `telegram`) maps to that vendor's factory output over the injected stub transport; a future enum member won't compile until registered (compile-time exhaustiveness).
- [ ] `selectWriteAdapter(registry, targetSystem)` is **prototype-safe** (`Object.hasOwn` guard) — `"__proto__"`/`"constructor"`/`"prototype"` and any unregistered target return `Result` err `{code:'unregistered_target'}`, never a fail-open truthy prototype member.
- [ ] `createUnroutedWriteAdapter()` returns a sentinel whose every op resolves `rejected` (defense-in-depth: if ever hit on the routed path, fail-closed — never a silent single-vendor write).
- [ ] `dispatchRouted(registry, action, deps)` selects by `action.targetSystem`, routes a known target to its vendor stub adapter, and maps an unknown target to `{status:'rejected'}` (PERMANENT fail-closed, not `held`/retry) WITHOUT performing a create.
- [ ] Each of the seven registered adapters produces a well-formed **stub `WriteReceipt`** (`stub-obj:<t>:<key>` shape, null→create→dedupe) — a contract test over all seven shapes.
- [ ] **Dormancy:** every target resolves to the injected stub; no real-transport path is reachable from the module (real transport binds only when 21.5/21.6 arm). The code-only fault never echoes the untrusted `targetSystem` (rule 7 redaction-safe).
- [ ] All unit tests in `packages/integrations/test/…` pass; `/preflight` clean.

## RED test outline (Step 2)
1. **`registry_routes_each_of_seven_targets`** — `selectWriteAdapter(registry, t).value.targetSystem === t` for all seven. Why: §19.8 G15/G16.

3. **`all_seven_adapter_shapes_contract`** — each registered adapter → well-formed stub `WriteReceipt` (null→create→dedupe). Why: G16.
4. **`no_real_transport_reachable`** — with an unset/stub transport injected, every create id is `stub-obj:`-namespaced (never `real:`); a factory-spy proves the real transport is never invoked. Why: §ARM-21 dormancy (safety).
5. **`unrouted_and_dispatch_routing`** — `createUnroutedWriteAdapter` rejects all ops typed; `dispatchRouted` → `{status:'rejected'}` on unknown target WITHOUT a create, and routes to the selected vendor stub on a known target. Why: no lingering single-adapter path + fail-closed.
