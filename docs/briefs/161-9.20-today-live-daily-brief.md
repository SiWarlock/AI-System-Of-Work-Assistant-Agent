# /tdd brief — today_live_daily_brief_and_schedule

## Feature
Flip the two hardcoded Today sections — "Daily brief" (Today.tsx:267-276) and "Today's schedule" (Today.tsx:282-308) — from literal placeholder strings to real data. The daily brief renders a DETERMINISTIC summary assembled from the hydrated store (recent changes + ingestion + approvals counts), so `SOW_DEMO_SEED=1 ./dev.sh` shows a genuinely populated brief (zero model calls). The schedule renders an honest state (no calendar connected) instead of mockup meeting rows.
